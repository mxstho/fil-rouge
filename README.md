# Solène Avril — Projet fil rouge
Reproduction en HTML/CSS d'une maquette de portfolio pour une photographe d'art. Le site présente une page d'accueil avec un menu de catégories et une galerie de photos, adaptée aux vues ordinateur, tablette et mobile.

🔗 Démo en ligne : https://mxstho.github.io/fil-rouge/

## Fonctionnalités

Présentation de la photographe.

Navigation par catégories : Nature, Portrait, Art, Urbain et Animaux.

Galerie de photographies.

Icônes de réseaux sociaux.

Mise en page adaptée aux ordinateurs, aux tablettes et aux mobiles.

## Technologies utilisées

HTML5 : structure du site.

CSS3 : mise en forme et mise en page responsive.

Google Fonts : polices Yeseva One et Montserrat.

Font Awesome : icônes.

Lorem Picsum : images utilisées pour la galerie.
